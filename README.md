# Live Requests demo

A click-through preview of a song request app for live musicians, with sample data.

- **Stage view** (`index.html`): what the performer sees during a show
- **Fan page** (`qr/index.html`): where a QR code on the table sends fans
- **Song list** (`request/index.html`): where fans pick a song and send a request

Everything is sample data saved in your own browser. Nothing is sent anywhere, and "Reset demo" in the top bar puts the sample data back.
